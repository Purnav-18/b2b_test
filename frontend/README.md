# Lead management frontend

The React/Vite dashboard for Only B2B Lead Management. It includes lead creation, validation feedback, search and filters, paginated results, and saved status changes.

For database configuration, API routes, and complete setup instructions, see the [project README](../README.md).

Run `npm run dev` for local development, `npm run lint` for lint checks, and `npm run build` for a production bundle. The Vite development server proxies `/api` requests to `http://localhost:3001`; override this with `API_PROXY_TARGET` when needed.
